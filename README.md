# My Omarchy Config

My Hyprland/Wayland dotfiles with custom tools and themes.

## Structure

- `bash/` - Bash configuration
- `ghostty/` - Ghostty terminal config with shaders
- `nvim/` - Neovim config with custom plugins
- `tmux/` - Tmux configuration
- `waybar/` - Waybar status bar config with themes
- `fastfetch/` - Fastfetch system info display
- `fontconfig/` - Font configuration
- `starship/` - Starship prompt config
- `wal/` - Pywal cache templates
- `wallpapers/` - Wallpapers
- `myTools/` - Custom scripts

## Installation

```bash
# Clone to ~/.config
git clone https://github.com/0xSCHfL/My-Omarchy-Conf.git ~/.config
```

Each subdirectory maps to `~/.config/<app>`.
