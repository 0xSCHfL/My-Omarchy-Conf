# Wallpaper & Pywal

## Setting Wallpaper

```bash
wallpaper-set.sh [/path/to/image]   # Set specific wallpaper
wallpaper-set.sh                     # Restore last pywal wallpaper
wallpaper-set.sh --no-wal [path]    # Set wallpaper without running pywal
```

- Picker: `Mod+Ctrl+Space` → wallpaper-pick.sh (rofi-based)
- From image picker: `Mod+Shift+i` → select image → `Alt+w`

## Pywal Color Flow

`wallpaper-set.sh` orchestrates everything:

1. `feh --bg-scale` sets the wallpaper
2. Copies wallpaper → `/usr/share/sddm/themes/i3-login/bg.jpg`
3. `wal -q -n -i <wallpaper>` generates color palette
4. **alacritty** → writes `~/.config/alacritty/alacritty-wal.toml`
5. **dunst** → runs `~/.config/dunst/generate-from-pywal.sh`
6. **SDDM theme** → writes `/usr/share/sddm/themes/i3-login/theme.conf`:
   - `background` = `special.background`
   - `foreground` = `special.foreground`
   - `accent`     = `colors.color3` (yellow)
   - `error`      = `colors.color1` (red)
   - `dimmed`     = `colors.color8` (bright black)
7. **flameshot** draw color → updates `~/.config/flameshot/flameshot.ini`
8. `xrdb -merge colors.Xresources` — loads colors into X resources

## Per-App Pywal Integration

| App | How |
|-----|-----|
| kitty | Includes `~/.cache/wal/colors-kitty.conf` |
| alacritty | Includes `alacritty-wal.toml` (generated by wallpaper-set.sh) |
| dunst | `generate-from-pywal.sh` rewrites dunst config and restarts dunst |
| SDDM login | `theme.conf` read by `Main.qml` via `config.accent` etc. |
| i3 | `set_from_resource` reads Xresources pywal colors |
| rofi | Reads pywal Xresources via `${xrdb:...}` in .rasi files |
| tmux | `.zshrc` runs `cat ~/.cache/wal/sequences` to set palette |

## Cache Files

| File | Contents |
|------|----------|
| `~/.cache/wal/wal` | Path to current wallpaper |
| `~/.cache/wal/colors.json` | Full palette as JSON |
| `~/.cache/wal/colors.sh` | Shell-sourceable colors (color0–color15) |
| `~/.cache/wal/colors.Xresources` | Xresources format |
| `~/.cache/wal/colors-kitty.conf` | kitty color config |
| `~/.cache/wal/sequences` | Terminal escape sequences |

## SDDM Theme Color Reading

`Main.qml` reads colors from `theme.conf` via the `config` object:

```qml
property string clrAccent: config.accent     || "#d4d232"
property string clrFg:     config.foreground || "#c0b18b"
property string clrBg:     config.background || "#262626"
property string clrError:  config.error      || "#d75f5f"
property string clrDim:    config.dimmed     || "#5a5a5a"
```

The `|| fallback` values ensure the theme works before any wallpaper is set.
