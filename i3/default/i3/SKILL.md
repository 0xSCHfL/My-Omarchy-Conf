# i3 Skill

Manage i3/X11 desktop configuration, related dotfiles, SDDM login theme, and live session debugging.

## Project Structure

```
~/Work/dotfiles/i3/
├── .config/i3/config                 # All keybindings, startup, window rules
├── .config/i3/scripts/
│   ├── wallpaper/                    # wallpaper-set.sh (pywal hub), wallpaper-pick.sh, wallpaper-next.sh
│   ├── media/                        # volume-osd.sh (yad OSD), i3-launch-wifi.sh, i3-launch-audio.sh
│   ├── launchers/                    # i3-email-picker.sh
│   ├── notifications/                # notifications.sh
│   └── utils/                        # float-toggle.sh, focus-next.sh, maximize.sh
├── .config/i3blocks/config           # Bar config (status_command = i3blocks)
├── .config/i3blocks/scripts/         # window-title, audio, wifi, battery, disks, systemstats, timer, spotify
├── .config/polybar/                  # Polybar config + launch.sh
├── .config/rofi/                     # Launcher themes (i3-launcher.rasi, dwm-keys.rasi)
├── .config/kitty/                    # Includes ~/.cache/wal/colors-kitty.conf
├── .config/alacritty/                # Includes alacritty-wal.toml (generated by wallpaper-set.sh)
├── .config/dunst/                    # Notification config + generate-from-pywal.sh
├── .config/tmux/                     # tmux config
├── .config/nvim/                     # Neovim config
├── .local/bin/                       # All custom i3 scripts
├── shell/                            # .zshrc, .zshenv, .zsh_aliases (stow separately)
├── .xinitrc.i3                       # X session startup
└── sddm-theme/i3-login/              # SDDM login theme (symlinked to /usr/share/sddm/themes/i3-login)
    ├── Main.qml                      # Login UI (QtQuick 2.0 + SddmComponents 2.0 only)
    ├── theme.conf                    # Pywal colors (rewritten by wallpaper-set.sh)
    ├── logo.svg                      # Pixel-art logo (#c0b18b)
    └── bg.jpg                        # Wallpaper copy (synced by wallpaper-set.sh)
```

## Working Rules

- Inspect the dotfiles source first, then edit.
- Edit in `~/Work/dotfiles/i3/` and restow — never edit live symlink targets directly.
- SDDM theme edits are immediately live (directory is a symlink, no copy needed).
- Do not add Wayland/Hyprland assumptions to i3 paths or scripts.
- When keybindings change, update `i3-keys` script and `references/keybindings.md`.
- `window-title` i3blocks script output must HTML-escape `&`, `<`, `>` — Pango markup parses it.
- `Main.qml` for SDDM: only `QtQuick 2.0` + `SddmComponents 2.0`. No `QtQuick.Controls` or `QtQuick.Layouts`.

## Apply & Verify

```bash
# Validate i3 config syntax
i3 -C -c ~/.config/i3/config

# Reload i3 (keybindings, rules — no restart)
i3-msg reload

# Restart i3 (full restart, re-runs exec_always)
i3-msg restart

# Restow i3 package
cd ~/Work/dotfiles && stow -t $HOME --restow \
  --ignore='^shell$' --ignore='^sddm-theme$' --ignore='^default$' i3

# Restow shell sub-package
cd ~/Work/dotfiles && stow -d i3 -t $HOME --restow shell
```

Targeted restarts:
```bash
pkill dunst && dunst &
pkill picom && picom --daemon
pkill i3blocks && i3blocks &
~/.config/polybar/launch.sh
wallpaper-set.sh          # Re-apply wallpaper + pywal + SDDM colors
```
