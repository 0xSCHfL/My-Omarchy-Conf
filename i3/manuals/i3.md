# i3 Manual

Local config: `~/.config/i3/config`

Full reference: `~/Work/dotfiles/i3/default/i3/references/keybindings.md`

## Launchers

| Key | Action |
|-----|--------|
| `Super+Space` | App launcher |
| `Super+Escape` | System menu |
| `Super+Alt+m` | Local manuals |
| `Super+Ctrl+k` | Keybinding help |
| `Super+Alt+k` | Keybinding help |
| `Super+Ctrl+b` | Battery CPU profile menu |
| `Super+Alt+c` | Run i3-check in a popup terminal |
| `Super+n` | Notes launcher |

## Core Keys

| Key | Action |
|-----|--------|
| `Super+Return` | Kitty |
| `Super+w` | Close focused window |
| `Super+h/j/k/l` | Focus direction |
| `Super+Shift+h/j/k/l` | Move window |
| `Super+1-0` | Switch workspace |
| `Super+Shift+1-0` | Move window and follow |
| `Super+o` | Toggle focused window as sticky picture-in-picture |
| `Super+x` | Lock |

## Media

## Runtime Checks

```bash
i3-check
i3-check --fix-perms
i3-check --dedup
i3 -C -c ~/.config/i3/config
i3-msg reload
i3-msg restart
```

## Important Scripts

- `i3-keys`: keybinding help
- `i3-sys`: system menu
- `i3-check`: validate config/scripts/dependencies/docs drift
- `i3-cpufreq`: auto-cpufreq menu
- `i3-gdrive`: Google Drive TUI; press `m` to mount the selected account, `M` to mount all accounts under `~/GoogleDrive/`
- `notes`: local notes launcher
- `i3-dedup`: revive/cleanup duplicate daemons
